# dev



This repo is the design of the dev blog — essays, projects, and the code behind the site.



- next.js v16 app router & react server components
- mdx (rust compiler) & shiki for content parsing
- tailwind css v4 & motion for styling and animations
- `<ViewTransition/>` from react experimental
- admin dashboard built with supabase
- static objects hosted on cloudflare r2 & cdn

The minimal layout takes inspiration from [rushil.me](https://rushil.me/).


```bash
pnpm install
pnpm dev
```

open [http://localhost:3000](http://localhost:3000) to preview locally.
